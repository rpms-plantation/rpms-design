Rubber Plantation Management System

High-Level System
Architecture

Modular pluggable microservices architecture — each module is an independently deployable vertical slice (backend + frontend + migrations) sharing a single PostgreSQL database. Built on Java 21, Spring Boot 3, Quarkus, Angular 18, and Kotlin Multiplatform, deployed on Kubernetes with Apache Kafka event backbone, IoT telemetry, blockchain provenance, and Gen AI intelligence.
