1. The Three-Repository Strategy on GitHub

GitHub Free gives you unlimited private repositories with unlimited collaborators. Repos should stay under 1 GB each (5 GB hard limit). Separate concerns into three repos to keep things organized and maintainable as the team grows.

2. Living Documentation — Notion (Free Tier)

Notion's free plan gives you unlimited pages and blocks for personal use, or up to 10 guest collaborators on a free team plan. Use it for living documents that change frequently and aren't suited to Git version control.

What goes in Notion (NOT in GitHub)
FREE — Notion Free Plan
  • Project roadmap & sprint planning — Kanban boards, timelines, task tracking
  • Meeting notes & decisions log — daily/weekly standup notes, stakeholder meeting records
  • Requirements & user stories — living documents that evolve through discussions
  • Team onboarding guide — how to set up dev environment, coding standards
  • Vendor evaluations — IoT device comparisons, cloud provider evaluation notes
  • Research notes — rubber plantation domain knowledge, industry standards
  • Links to GitHub artifacts — each Notion page links directly to the relevant repo files

Rule of thumb: If it's a versioned deliverable (DDL, code, diagram file) → GitHub. If it's a living discussion document → Notion.

4. CI/CD — GitHub Actions (Free Tier)

GitHub Free includes 2,000 CI/CD minutes/month for private repos. For a small team starting out, this is more than enough for running builds, tests, and deployments.

What to automate early
FREE — 2,000 min/month
  • DDL validation — Run SQL syntax checks on every PR to the design repo
  • Mermaid rendering — Auto-generate PNG from .mermaid files on commit
  • Build & test — Maven/Gradle builds for Spring Boot, Quarkus native builds
  • Docker image builds — Build container images, push to GitHub Container Registry (free for public, included storage for private)
  • OpenAPI validation — Lint API specs on every change
