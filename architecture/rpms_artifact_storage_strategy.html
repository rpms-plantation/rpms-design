4. CI/CD Pipeline Per Module

Each module repo runs an independent 4-stage GitHub Actions pipeline. PRs run stages 1–2; main pushes run all 4. Pipeline time: <10 minutes per module.

STAGE 1
Build + Test (parallel)
Backend: Maven/Gradle, Testcontainers (PG+Kafka)
Angular: ng lint, ng build, Jasmine
KMP: Gradle, kotlin.test, lint
STAGE 2
Quality Gates
Avro schema check
OpenAPI lint (Redocly)
Flyway validate
Pact contract tests
STAGE 3
Publish (main only)
Docker → GHCR
Angular → npm
KMP → Maven
STAGE 4
Deploy (main only)
Flyway migrate staging
ArgoCD sync K8s
Webhook → shell rebuilds

6. Living Documentation — Notion (Free Tier)

What goes in Notion (NOT in GitHub)
FREE — Notion Free Plan
  • Project roadmap and sprint planning — Kanban boards, per-module task tracking
  • Meeting notes and decisions log — standup notes, stakeholder records
  • Requirements and user stories — living documents
  • Module team assignments — who owns which repo
  • Team onboarding — dev environment setup, clone repos, run docker-compose
  • Research notes — rubber plantation domain knowledge
  • Links to GitHub — each page links to relevant repo files

Rule: Versioned deliverable → GitHub. Living discussion → Notion.
